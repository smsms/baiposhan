# 行程预算测算规范

用于给分日旅行计划配套输出预算。所有数字均为**估算区间**，必须以区间形式输出，禁止给出"精确总价"或"已确认价格"的表述。

## 一、预算档位基准

人民币，参考区间，按下述口径取值后按实际目的地消费水平上下浮动（一线/热门旅游城市上浮 20%–40%，三四线及县域下调 15%–30%）。

| 项目 | 节约 | 轻奢 | 奢华 | 计量口径 |
|---|---|---|---|---|
| 住宿 | 150–350 | 400–800 | 900–2000+ | 元 / 间 / 晚 |
| 餐饮 | 40–80 | 100–200 | 250–500 | 元 / 人 / 天（含早中晚） |
| 门票与体验 | 50–120 | 100–200 | 150–350 | 元 / 人 / 天（按景点实际累加） |
| 市内交通 | 20–40 | 50–100 | 100–300 | 元 / 人 / 天（奢华含包车/专车） |
| 弹性杂项 | 10% | 10% | 10% | 上述四项合计的 10% |

城际交通（往返大交通、跨城高铁/机票）**单列**，不套用档位，按出发地与目的地实际线路给区间；用户未给出发地时标注"未含大交通，需补充出发地后测算"。

## 二、计算规则

1. N 天行程默认 N−1 晚住宿；含返程当日不住宿时按实际晚数计。
2. 人均住宿 = 房费区间 × 晚数 ÷ 同住人数（默认 2 人一间）；单人出行需额外标注"含单房差"。
3. 门票按当日实际安排的景点逐个累加；免费景点写 ¥0 并注明"免费"。
4. 弹性杂项 = （住宿 + 餐饮 + 门票 + 市内交通）× 10%，用于覆盖临时打车、寄存、饮水等零散支出。
5. 所有结果取整到十位，先算人均再算团队总价（团队总价 = 人均 × 人数）。
6. 上下限分别计算，输出"¥X–Y"形式的区间，不取中间值假装精确。

## 三、档位与偏好的联动

- **节约**：经济型连锁/民宿/青旅；以地铁公交+步行为主；免费或低价景点占比 ≥ 50%；餐饮以本地小馆、小吃为主。
- **轻奢**：精品酒店或中高端连锁；打车+地铁混用；保留 1–2 个付费重点项目（如景区门票、游船、演出）；餐饮含 1 顿当地口碑餐厅。
- **奢华**：度假酒店或高星；包车/专车接送；可含私导、演出好座、特色体验；餐饮含高端餐厅或酒店餐厅。

用户说"尽量省钱""控制在 X 元以内"时，以用户给的硬上限为第一约束：先按节约档位铺排，再核算是否超限，超限则替换高价项目并说明替换逻辑。

## 四、示例演算（3 天 2 晚 · 2 人 · 轻奢）

| 项目 | 单价区间 | 数量 | 人均小计 |
|---|---|---|---|
| 住宿 | 400–800 元/间/晚 | 2 晚 ÷ 2 人 | 400–800 |
| 餐饮 | 100–200 元/人/天 | 3 天 | 300–600 |
| 门票与体验 | 100–200 元/人/天 | 3 天 | 300–600 |
| 市内交通 | 50–100 元/人/天 | 3 天 | 150–300 |
| 弹性杂项 | 上四项 × 10% | — | 115–230 |
| **人均合计** | | | **¥1270–2530** |
| 团队总计（2 人） | | | **¥2540–5060** |

## 五、禁忌

- 不编造具体酒店房价、景区门票价、机票价格作为确定数值。
- 不写"已核实真实价格""价格已确认"等断言。
- 不在预算里出现未在当日行程中安排过的项目（门票必须对应行程里的景点）。
- 不遗漏弹性杂项，也不把弹性杂项算成整数凑总额。
